# SWYNEX Final Data Analytics Project

## Project Title
Adult Census Income Analysis

## 1. Problem Statement
The objective of this project is to analyze adult census data to understand how factors such as education, workclass, age, and working hours relate to income levels.

## 2. Dataset Information
The project uses the Adult Census Income dataset containing demographic and employment information.

The dataset includes age, workclass, education, occupation, sex, capital gain, capital loss, hours worked per week, and income.

## 3. Data Cleaning and Preparation
Data cleaning was performed using Python and Pandas.

- Identified and handled missing values.
- Replaced missing categorical values with "Unknown".
- Removed duplicate records.
- Checked data quality after cleaning.
- Saved the cleaned dataset for further analysis.

## 4. Exploratory Data Analysis
Exploratory Data Analysis was performed to identify patterns and trends in the data.

The analysis examined income distribution, education levels, workclass, and working hours.

## 5. Key Findings
- Approximately 75.91% of records belong to the <=50K income group.
- Approximately 24.09% belong to the >50K income group.
- The private sector accounts for approximately 69.68% of records.
- People in the >50K income group work an average of approximately 45.47 hours per week, compared with 38.84 hours for the <=50K group.
- Higher education levels, including Doctorate and Professional School, show higher proportions of records earning >50K.

## 6. Interactive Dashboard
An interactive dashboard was created using Microsoft Power BI.

It includes KPI cards, income and education charts, workclass distribution, working-hours analysis, and interactive filters.

## 7. Tools Used
- Python
- Pandas
- Exploratory Data Analysis
- Microsoft Power BI
- GitHub

## 8. Conclusion
This project demonstrates a complete data analytics workflow, from data cleaning and exploratory analysis to interactive visualization and business insights.

The findings describe associations in this dataset and do not prove that education or working hours directly cause higher income.
